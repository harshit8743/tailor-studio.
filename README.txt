TAILORDESK — STARTER PROJECT

Files:
- index.html: page structure and forms
- styles.css: responsive design and visual styling
- app.js: order/customer/measurement/payment logic and browser storage

RUN:
1. Extract the ZIP.
2. Open the tailordesk folder.
3. Double-click index.html (Chrome/Edge recommended).
4. Click New order and create a test order.

IMPORTANT:
This is a functional front-end prototype. It stores records in localStorage in the current browser profile.
It is NOT yet a secure multi-user commercial SaaS. Browser storage is not shared across devices and can be cleared.
Before using for real customer records or selling it, add a backend/database, authentication, role permissions,
automated backups, secure image/file storage, privacy notice, and deployment over HTTPS.

CUSTOMISATION:
- Change the shop name in index.html (TailorDesk text).
- Change colours near the top of styles.css (:root).
- Change currency formatting in app.js (money function).
- Add fields in the order form in index.html and save/render them in app.js.
